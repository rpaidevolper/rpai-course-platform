## 概述 (Overview)

**品牌概述 (Business Overview)：**
RPAI 數位優化器是台灣知名的自動化與 AI 諮詢社群，專注於 RPA（機器人流程自動化）與 AI 整合。我們提供專業顧問諮詢、一對一教練、企業培訓與數位產品開發。核心目標是協助非技術專業人士與組織，透過低程式碼（Low-code）工具自動化工作流程，並大幅提升生產力。

**品牌美學 (Brand Aesthetic)：**
`現代` | `企業感` | `科技導向` | `俐落` | `專業` | `高純淨感 (Translucent Laboratory)`

**創意北極星 — The Digital Clinical：**
高純淨感、未來實驗室般的介面美學。透過高清晰字體排印、大面積留白、以及背景色階的層次感，營造出深度與精緻的視覺氛圍。拒絕「模板感」：不要中規中矩地對齊所有元素。以 Deep Navy 作為視覺重力錨點，Vibrant Teal 僅在深色頁面中擔任動態引導的角色。透過 **淺深交替節奏** 與 **色階層次 (Tonal Depth)** 取代傳統邊框分隔，營造科技感與呼吸感兼具的視覺體驗。

**關鍵字**：RPA, AI, 數位轉型, low-code, 工作流程自動化, 專業顧問, 科技風格, Translucent Laboratory

## 視覺規範 (Visual Guidelines)

### 色彩系統 (Colors)

本品牌以雙模式（淺色頁面 / 深色頁面）為基礎，搭配嚴格的色彩分配規則。

**核心色票：**

| Token | Hex | 角色 | 使用場景 |
|-------|-----|------|----------|
| **Navy** | `#011455` | 主色 / 錨定色 | 深色頁面的背景；淺色頁面的**文字色與線性強調色**（描邊圈、強調條、大字數字、強調線）。**淺色頁不可作填色面。** |
| **Teal** | `#7AFFF5` | 動態強調色 | **僅限深色頁面** — 互動元素、進度、狀態 |
| **White** | `#FFFFFF` | 卡片 / 文字 | 淺色頁面的卡片底色；深色頁面的文字 |
| **Ice**(舊名 Ash) | `#E9F3F5` | 基底表面 | 淺色頁面的背景色 |
| **IceD**(舊名 Surface) | `#DBEAEE` | 微層次 | 淺色頁面中用來區分區域、徽章、圖示底圈 |

**輔助色：**

| Token | Hex | 用途 |
|-------|-----|------|
| **Body** | `#454650` | 淺色頁面正文文字 |
| **Label** | `#454650`(70% 不透明度) | 淺色頁面技術標籤(以透明度降階,不引入獨立色相) |
| **NavyD** | `#000D3A` | 深色頁面微層次（Q&A 條目底色等） |

### 三條絕對規則

這三條規則是品牌視覺的核心約束，任何產出（簡報、網頁、社群貼文）都必須遵守：

**規則 1：每頁最多三色**
任何一張投影片 / 一個區塊上，出現的「填色色塊」不超過三種。文字色不算在內（例如 Navy 同時作為文字色和某個色塊的填色，只算一次）。

**規則 2：淺色頁面禁止 Navy「填色面」，但允許 Navy「線性強調」**
`#011455` 在淺色頁面（Ice 背景）中**不得作為任何填色色塊 / 填色面**（卡片、banner、side bar、實心圓、大面積色面）——這條不變，是品牌「高純淨感、留白呼吸」的根本。

但 Navy **可以、也應該**作為淺色頁的**強調色**，形式限定為「線 / 描邊 / 字」三種，不是「面」：
- **描邊圈**（數字圈、徽章外框，線寬 1.5–2.5pt）
- **強調細條**（左側 / 頂部強調條，寬度 **≤ 0.1 吋**）
- **大字級數字、強調分隔線**

**一句話判準：面（fill）禁止；線（stroke）、字（text）允許。** 頂部全寬裝飾線（h ≤ 0.07 吋）仍為既有允許項。細節見下方「淺色頁強調層級（Emphasis Tiers）」。

**規則 3：淺色色塊禁止搭配 Teal**
`#7AFFF5` 不得出現在以淺色為底的頁面或區域中。Teal 只在 Navy 背景上使用。

### 頁面類型色彩表

| 頁面類型 | 背景 | 可用填色 | 文字色 | Teal |
|----------|------|----------|--------|------|
| **深色頁面**（封面、段落分頁、Q&A、結語） | Navy | Navy / Teal / White | White, Teal | 可用 |
| **淺色頁面**（所有內容頁） | Ice | White / IceD | Navy, Body(`#454650`), Label(`#454650` 70% 不透明度) | 禁用 |

> 淺色頁的 **Navy 強調**（描邊圈、強調條 ≤ 0.1 吋、大字、強調線）屬「線 / 字」不屬「填色面」，**不佔「可用填色」欄，也不違反規則 2**。

### 表面層次 — 淺色頁面

用背景色階取代邊框來劃分區域（**分區用**，不是強調用）：

1. **基底** — Ice `#E9F3F5`（投影片背景）
2. **卡片** — White `#FFFFFF`（內容容器）
3. **微層次** — IceD `#DBEAEE`（特色區塊、圖示底圈、數字徽章、分隔線）

三者屬於同一色調家族，不算三種獨立色彩。

> **注意**：以上三階只負責「分區」。要讓某個元素「被記住 / 被強調」，不要靠 IceD（它太淺，會跟白卡黏在一起，造成「該強調卻沒強調」）——請改用下面獨立的「強調層」。

### 淺色頁強調層級（Emphasis Tiers）

**問題背景**：過去淺色頁只有「色階分區」（Ice → White → IceD），沒有獨立的「強調」手段。結果需要被記住的元素（帶走頁重點、轉折句、關鍵數字）只能用 IceD，淡到跟白卡黏在一起——這就是「明明該強調卻沒強調」的根因。

**解法**：淺色頁新增一條**獨立於色階的強調層**，用 **Navy 的線性形式**（不是填色面）來製造重量。

| 層級 | 目的 | 手段 | 用在哪 |
|------|------|------|--------|
| 分區（既有） | 只是跟旁邊分個層 | IceD `#DBEAEE` 底 | 一般次區塊、徽章底、分隔 |
| **強調（新增）** | 讓觀眾停留 / 記住 | **Navy 線性**：描邊圈、強調條、大字、強調線 | 帶走頁數字、轉折句、關鍵句、章節重點 |

**強調的四種標準形式（Navy，線 / 字，非面）：**

1. **描邊圈**：White 底 + Navy **1.5–2.5pt** 外框 + Navy 數字（取代弱的 IceD 底圈；這是數字圈的**預設強調寫法**）
2. **左強調條**：白卡左側 Navy 直條，寬度 **≤ 0.1 吋**（是線，不是面）
3. **大字數字**：Navy 大號 01 / 02 / 03，去掉圈圈，靠字級製造重量
4. **強調分隔線**：Navy 細線（比 IceD 分隔線深一階，用在重點區塊上 / 下）

**判準（Claude 產出時必做）：**

> 這個元素的目的是「被記住 / 停留」 → 用 **Navy 線性強調**。
> 只是「跟旁邊分層」 → 才用 **IceD**。
> **一頁裡只要有「重點 / 帶走 / 轉折 / 關鍵數字」，至少要有一處 Navy 線性強調，不能整頁只剩 IceD。**

**仍然禁止**：Navy 實心圓、Navy banner、Navy 大色塊——任何「面」形式的 Navy 填色，一律不行。要更強的衝擊時，正解是**把整頁改成深色頁**（Navy 底 + Teal 強調），而不是在淺頁塞 Navy 色塊。

### 表面層次 — 深色頁面

1. **基底** — Navy `#011455`（投影片背景）
2. **深層** — NavyD `#000D3A`（Q&A 條目底色等微層次）
3. **強調** — Teal `#7AFFF5`（標題文字、左側標記條、數字徽章）

## 字體排版 (Typography)

- **英文字型**：**Trebuchet MS**（幾何風格、科技感、廣泛支援），備用 Calibri / Arial。
- **中文字型**：**Noto Sans TC / 思源黑體**（備用 Microsoft JhengHei）。中文字型不得省略，RPAI 以中文為主。

### Type Scale

| 元素 | 字級 | 字重 | 色彩（淺色頁） | 色彩（深色頁） |
|------|------|------|----------------|----------------|
| 投影片標題 | 25pt | Bold | Navy | — |
| 封面主標 | 50pt | Bold | — | White |
| 段落分頁標題 | 40pt | Bold | — | White |
| 卡片標題 | 15–18pt | Bold | Navy | White 或 Teal |
| 正文 | 12–14pt | Regular | Body `#454650` | White |
| 技術標籤 | 10pt | Bold | Body `#454650`(70% 不透明度) | Teal |
| 頁尾 | 8–9pt | Regular | Body（45% 透明） | White（50% 透明） |

字距（charSpacing）：封面主標 `-1`，大號 Q&A `-2`，其餘預設。

## 陰影與深度 (Elevation & Depth)

**原則：用色階取代陰影。** 陰影僅在必要時使用，且必須以 Navy 調色。

| 場景 | 設定 |
|------|------|
| 一般卡片 | `blur:16, offset:3, angle:135, color:011455, opacity:0.06` |
| 輕量卡片 | `blur:8, offset:2, angle:135, color:011455, opacity:0.04` |
| 浮動元素（modal） | `blur:40, offset:8, angle:135, color:011455, opacity:0.05` |

**禁止：**
- 使用 `#000000` 陰影
- 使用 1px 實線邊框
- 巢狀卡片加 drop shadow

**圓角**：如需圓角使用 RECTANGLE + shadow，不使用 ROUNDED_RECTANGLE（避免與矩形裝飾條不匹配）。

## 元件模式 (Components)

### 深色頁面 — 段落分頁

```
背景: Navy #011455
左側 Teal 細條: x:0.55, w:0.06, h:1.5
浮水印數字: 200pt, Teal, transparency:88
標題: 40pt Bold White
副標: 15pt White (transparency:30)
右下 RPAI 徽章: 10pt Teal
```

### 淺色頁面 — 內容頁

```
背景: Ice #E9F3F5
頂部裝飾線: Navy, 全寬, h:0.06（唯一允許的 Navy 色塊）
標題: 25pt Bold Navy
內容卡片: White 填色, Navy shadow
頁尾: 8pt Body色, 靠右
```

### 編號列表（淺色頁面）

```
白色卡片全寬
數字圈（依重要性選一階）：
  · 預設 / 強調 → White 底 + Navy 1.5–2.5pt 描邊圈 + Navy 數字（避免太弱，帶走頁/重點列一律用這個）
  · 或 → Navy 大字數字，不加圈（靠字級製造重量）
  · 純分區、非重點 → 才降為 IceD 底圈 + Navy 數字
右側: Navy 標題 + Body 正文
分隔: IceD 細直線 (w:0.04)；若為重點列，可升級為 Navy 細強調線
不使用 Navy 實心圓作為數字底（禁填色面）
不使用 Teal（淺頁禁 Teal）
```

### 三欄卡片（淺色頁面）

```
三張等寬 White 卡片
上方圓圈：
  · 一般 → IceD 底圈 + Navy 圖示/數字 (react-icons PNG)
  · 帶走頁/重點頁 → White 底 + Navy 描邊圈 + Navy 圖示/數字（強調升級，見「淺色頁強調層級」）
中間: Navy Bold 標題文字
下方: IceD 色條紋作為內容底色
欄間箭頭: Navy 文字 "→" (transparency:30)
特色卡片: 改用 IceD 底色取代 White（微層次差異）；或用 Navy 左強調條 (w≤0.1吋) 標記
不將中間卡片改為 Navy 底色（禁填色面）
```

### 流程圖（淺色頁面）

```
圓形或矩形節點: White 或 IceD 填色
箭頭文字: Navy "→" 或 "›" (transparency:30)
特色節點: IceD 底色（非 Teal、非 Navy）
```

### 關鍵訊息（淺色頁面）

```
白色卡片 + 大號 Navy Bold 文字置中
強調升級（擇一）：左側 Navy 強調條 (w≤0.1吋) / 放大字級 / 上下 Navy 強調分隔線
下方 IceD 細線分隔（一般）
副訊息以 Body 色正文呈現
不使用 Navy 色塊作為「高亮」背景（禁填色面；改用線性強調）
```

> **轉折句 / 過場句**（例如「但如果進來的是一段文字呢？」）屬於「要被記住」的元素，**不可只用 IceD 淡底**。標準寫法：白卡 + Navy 左強調條 (w≤0.1吋) + Navy 文字，或無底 + 放大 Navy 字置中。

## 圖示 (Icons)

使用 **react-icons** 轉 PNG（256px+ 解析度），確保跨平台顯示一致。

**禁止使用 emoji** — 在 LibreOffice / PDF 轉換中無法可靠渲染。

| 頁面類型 | 圖示色 | 底圈色 |
|----------|--------|--------|
| 淺色頁面 | Navy `#011455` | IceD `#DBEAEE` |
| 深色頁面 | Teal `#7AFFF5` 或 White | NavyD `#000D3A` |

## 間距 (Spacing)

| 元素 | 間距 |
|------|------|
| 投影片邊距 | ≥ 0.4 吋 |
| 卡片間距 | 0.12–0.2 吋 |
| 主要區段之間 | ≥ 0.6 吋 |
| 欄位間距（三欄） | 3.1 吋 per column，gap ≈ 0.2 吋 |
| 標題與內容 | 0.08–0.15 吋 |

## Do's & Don'ts

### Do
- **Do** 擁抱留白 — 主要區段之間使用 0.6 吋以上的間距。
- **Do** 用色階分區 — White 卡片放在 Ice 背景上，IceD 條紋放在 White 卡片裡。
- **Do** 淺頁「該強調處」用 **Navy 線性強調**（描邊圈 / 左強調條 w≤0.1吋 / 大字 / 強調線）——IceD 只做分區、不做強調，避免「明明該強調卻沒強調」。
- **Do** 字級對比 — 標題 25pt+ vs 正文 12–14pt，拉開層次。
- **Do** 深淺交替 — 封面（深）→ 內容（淺）→ 段落分頁（深）→ 內容（淺）……形成節奏。
- **Do** 深底文字使用 `#FFFFFF` 或 Teal `#7AFFF5`，確保高對比。
- **Do** 以 surface 色階層疊表達深度，取代傳統邊框。
- **Do** 使用 react-icons 轉 PNG 作為圖示。
- **Do** Shadow factory — 每次 addShape 呼叫都建立新的 shadow 物件，避免 pptxgenjs 的物件突變 bug。

### Don't
- **Don't** 同一頁超過三色 — 永遠不要。
- **Don't** 淺色頁面放 Navy **填色面** — `#011455` 不能是卡片 / banner / 實心圓 / 大色塊的填色；但**描邊圈、強調條 (w≤0.1吋)、大字、強調線是允許且鼓勵的**（見「淺色頁強調層級」）。
- **Don't** 淺色頁面放 Teal — `#7AFFF5` 完全禁止出現在淺色區域。
- **Don't** 使用純黑 `#000000` 作為陰影或背景。
- **Don't** 使用 1px 灰色分隔線 — 用背景色階取代。
- **Don't** 使用 emoji — 用 react-icons 轉 PNG。
- **Don't** 共用 shadow 物件 — pptxgenjs 會原地修改物件，必須每次建立新物件。

## 技術細節 — SCSS / CSS

```scss
/* Core Brand Colors — Translucent Laboratory */
$navy:    #011455;   // Primary / anchor
$teal:    #7AFFF5;   // Dynamic accent (dark contexts ONLY)
$white:   #FFFFFF;   // Cards / text
$ice:     #E9F3F5;   // Light page background(舊 $ash,已統一為定稿冰青)
$iced:    #DBEAEE;   // Subtle surface shift(舊 $surface) — 分區用，非強調用

/* Light-page emphasis — Navy 線性強調（非填色面）：描邊圈 / 強調條 / 大字 / 強調線 */
$emphasis-stroke:       #011455;   // Navy，用於 border / outline / rule，不用於 fill
$emphasis-stroke-width: 2px;       // 描邊圈 1.5–2.5pt 對應
$emphasis-bar-max:      0.1in;     // 左/頂強調條寬度上限（超過即算填色面，禁止）

/* Text */
$text-navy:  #011455; // Headings on light pages
$text-body:  #454650; // Body text on light pages
$text-label: rgba(69, 70, 80, 0.7); // Metadata labels: Body 色 70% 不透明度降階
$text-white: #FFFFFF; // Text on dark pages

/* Dark Page Depth */
$navy-deep: #000D3A;  // Micro-layer on dark pages

/* Shadow (Navy-tinted only, never #000) */
$shadow-color:   #011455;
$shadow-opacity: 0.06;

/* Radii */
$radius-md:   0.75rem;  // 12px
$radius-lg:   1rem;     // 16px
$radius-full: 9999px;
```

## 快速自檢清單

製作完成後逐頁檢查：

- [ ] 這頁有幾種填色？是否 ≤ 3？
- [ ] 如果是淺色頁面：有沒有 Navy **填色面**（實心圓 / banner / 色塊）？有沒有 Teal？（都不該有）
- [ ] **這頁需要被記住的元素（重點 / 帶走 / 轉折 / 關鍵數字），有沒有用到 Navy 線性強調（描邊圈 / 強調條 / 大字）？還是又只剩 IceD 太弱？**
- [ ] Navy 是否只出現在「文字 / 描邊 / 線 / 大字」，沒有變成填色面？
- [ ] 如果是深色頁面：是否只有 Navy + Teal + White？
- [ ] 文字對比度足夠嗎？（淺底深字 / 深底淺字）
- [ ] 有沒有元素超出投影片邊界？
- [ ] 所有圖示是否用 react-icons PNG（非 emoji）？
- [ ] 頁尾是否與內容重疊？

## Gotchas

1. **套用風格 ≠ 改內容**：此 skill 僅規範視覺與語氣，不修改核心內容或數據。
2. **子 skill 矛盾時以本 skill 為準**。
3. **Teal `#7AFFF5` 僅限深色頁面**：絕對不可出現在淺色頁面的任何位置，包含文字、填色、邊框。
4. **Navy `#011455` 在淺色頁面不可作「填色面」**（卡片 / banner / 實心圓 / 大色塊），但**可作「線性強調」**：描邊圈 (1.5–2.5pt)、強調細條 (w ≤ 0.1 吋)、大字數字、強調分隔線，以及文字色。頂部全寬裝飾線 (h ≤ 0.07 吋) 仍為既有允許項。判準：**面禁止，線 / 字允許**。
5. **禁用純黑 `#000000`**：陰影必須以 Navy 調色。
6. **中文字型不得省略**：主字型為 Trebuchet MS / Calibri，但中文必須保留 Noto Sans TC / 思源黑體。
7. **禁用 emoji**：在 LibreOffice / PDF 轉換中無法可靠渲染，一律使用 react-icons 轉 PNG。
8. **pptxgenjs hex 色碼不加 `#`**：加了會導致檔案損壞。
9. **pptxgenjs shadow 物件不可共用**：每次 addShape 必須建立新的 shadow 物件實例。
10. **介面產品有專屬規範**:講師後台、儀表板等介面產品適用文末「介面產品設計系統」章節,其中 Navy 可作為小面積互動元素填色(介面例外)。此例外不回流至簡報與社群產線。全品牌淺色基底已統一為 Ice `#E9F3F5`(舊 Ash `#E9EEFF` 已於 v1.0 定稿時廢止)。

## 介面產品設計系統(Interface Extension)

**適用範圍**:講師後台、儀表板、互動教學工具、Web App 等「介面產品」。
**不適用**:簡報(.pptx)、社群貼文、文件產線 —— 這些仍完全遵守前述章節規範。

### 設計哲學:單色主義(Monochrome Interaction)

每個模式**只有一個互動色**,不引入任何新色相:

| 模式 | 唯一互動色 | 品牌語意 |
|------|-----------|---------|
| 淺色模式(N5) | Navy `#011455` | 錨點即行動 |
| 深色模式(D1) | Teal `#7AFFF5` | 深色世界的動態訊號 |

兩模式互為鏡像:冰青底 ↔ NavyD 底|白卡 ↔ Navy 卡|Navy 互動 ↔ Teal 互動。

### 淺色模式 N5

| Token | Hex | 角色 |
|-------|-----|------|
| **Ice** | `#E9F3F5` | 介面背景(與簡報/文件淺色基底同一 token) |
| **White** | `#FFFFFF` | 卡片 |
| **IceD** | `#DBEAEE` | 微層次(分區、徽章底、hover 列) |
| **Navy** | `#011455` | 互動主色 + 標題文字 |
| **NavyPress** | `#000D3A` | 按鈕按下狀態 |
| **NavyTint** | `#DCE4F5` | 次按鈕填色 / 選取態淡底 |
| **Body** | `#454650` | 正文文字 |

**元件規則:**
- 主按鈕:Navy 填色 + White 文字;按下改 NavyPress
- 次按鈕:NavyTint 填色 + Navy 文字
- 連結:Navy 文字 + 底線;狀態表達靠深淺、底線與字重,不靠新色
- 勾選框:勾選後 Navy 填色 + White 勾號

**介面例外條款**:介面產品中,Navy 允許作為按鈕、勾選框、進度條等**小面積互動元素**的填色。此為「淺色頁面禁止 Navy 色塊」規則之介面專屬例外;Navy 仍禁止作為大面積卡片、banner、區塊背景的填色。

### 深色模式 D1(深空反轉)

| Token | Hex | 角色 |
|-------|-----|------|
| **NavyD** | `#000D3A` | 介面背景(層級反轉:底比卡深) |
| **Navy** | `#011455` | 卡片(比底亮一階,靠明度浮起,不用邊框) |
| **NavyL** | `#1A2C6E` | 次按鈕填色 / 微層次 / 進度條軌道 |
| **Teal** | `#7AFFF5` | 互動主色 |
| **TealD** | `#54D8CD` | 按鈕按下狀態 |
| **White** | `#FFFFFF` | 主文字 |

**元件規則:**
- 主按鈕:Teal 填色 + Navy 文字;按下改 TealD
- 次按鈕:NavyL 填色 + **White 文字**(深色模式次要按鈕一律白字,禁用 Teal 文字於填色按鈕內)
- 連結:Teal 文字 + 底線
- 狀態徽章:Navy 或 NavyL 底 + Teal 文字
- 次要文字:White 60% 不透明度
- 勾選框:勾選後 Teal 填色 + Navy 勾號;未勾選 Navy 底 + Teal 1.5px 描邊

### 語意色(僅限介面產品)

| 語意 | 主色 | 淡底 | 用途 |
|------|------|------|------|
| 成功 | `#1E7A4E` | `#E7F2EC` | 閘門通過、勾核完成 |
| 警示 | `#B26B00` | `#F7EFE0` | 逾期提醒、缺件 |
| 錯誤 | `#B3352E` | `#F7E7E6` | 失敗、阻斷 |

**規則**:語意色只做小面積徽章、文字、圖示與細線,**永不做大色塊**;深色模式下語意色文字直接用於 Navy 卡片上,不另建深色變體淡底。

### 對比基準(WCAG)

- Navy on White:15.9:1|Navy on Ice:14.6:1(AAA)
- White on Navy:15.4:1|Teal on Navy:13.2:1(AAA)
- White on NavyL `#1A2C6E`:9.6:1(AAA)
- 語意色 on White:全數 ≥ 4.9:1(AA)
