# 逐頁講稿併入簡報的 speaker notes

帳號層 `rpai-course-content` 2026-10-23 的調整，不再產出逐頁腳本（MD）：逐頁講稿、互動提示與示範指令寫在 PPTX 的 speaker notes，逐頁結構在產簡報前的確認閘（簡報大綱）確認。所以逐頁腳本不再是獨立產物，這取代 [ADR 0003](0003-page-script-as-upstream-artifact.md) 裡「逐頁腳本是產物」的部分；「產物可以讀一份上游產物，但前提只能來自藍圖」的原則不變，只是簡報的上游現在只有藍圖，學員手冊的上游是那一天的簡報。

學員手冊一天一份、HTML 單檔，只有含動手環節的天才產；純講述的天不產手冊，也不以講義取代。

## Considered Options

- **維持 ADR 0003，逐頁腳本是獨立產物**：講師要多確認、多維護一份文件，而且平台的做法會和團隊實際使用的 skill 不一致，講師裝到的 plugin 產出的東西和平台期待的對不上。
- **講稿寫在簡報的 speaker notes（採用）**：講稿和投影片同一份檔案，不會對不上；逐頁結構的確認改在簡報大綱這個閘。

## Consequences

- 定稿閘：藍圖定稿才能產簡報；某一天的簡報定稿，才能產那天的學員手冊。
- 結案閘：每一天都有最終版簡報才能結案（原本是逐頁腳本加簡報）（2026-10-24 修訂：有動手環節的天另外要有最終版學員手冊，#107）。
- 產物種類只剩課程大綱、簡報、學員手冊（與講師準備單）；設計稿的產物鏈要拿掉逐頁腳本（#81）。
- 學員手冊 v1 只提供下載，不在平台網域內渲染或預覽，避免在平台網域上執行上傳的 HTML。
- plugin 的 `rpai-*` skill 要與帳號層同步，runner 與 spec、architecture 的手冊格式與產物鏈一併更新（#63）。
