# 逐頁腳本是產物，簡報與學員手冊以它為上游

講師實際的工作順序是「課綱確認 → 逐頁腳本 → 簡報、學員手冊」，而且最常抱怨的是「藍圖和逐頁內容不一致」。所以逐頁腳本是一種產物，簡報與學員手冊除了綁定藍圖版本，還綁定一份上游的逐頁腳本；藍圖或腳本任一過期，下游都標示過期。藍圖仍是所有前提（受眾、時數、工具、情境）的唯一來源，腳本只負責「每頁講什麼」。這是對「所有生成一律讀藍圖」的刻意放寬：產物可以讀一份上游產物，但前提只能來自藍圖。

## Considered Options

- **把逐頁內容寫進藍圖**：藍圖會大到每改一頁就升一版，藍圖對話也得處理逐頁細節。
- **腳本只是產簡報時的中間檔**：簡報與手冊各自重新展開內容，正是現在「兩邊對不上」的來源，也沒有地方讓講師先確認腳本再產簡報。
